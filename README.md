# 몽글온실 🌷

세로 화면용 꽃 키우기 게임의 플레이 가능한 프로토타입입니다. 현재 HTML/CSS/JavaScript로 구현되어 있으며, Android/iOS 설치형 앱 빌드는 포함하지 않습니다.

## 실행

Node.js 18 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm start
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. 파일을 수정한 후 새로고침하면 반영됩니다. 이미 4173 포트를 사용 중이면 기존 서버를 종료하거나 `PORT` 환경 변수로 다른 포트를 지정하세요.

```sh
npm run check
```

위 명령은 JavaScript 문법을 검사합니다.

## 수정할 파일

| 파일 | 역할 |
| --- | --- |
| `dist/index.html` | 온실 화면, 메뉴, 팝업 구조 |
| `dist/game.js` | 성장, 색상, 교배 확률, 판매, 상점, 저장 |
| `dist/portrait.css` | 세로 게임 화면과 온실 배치 |
| `dist/portrait.js` | 세로 화면 크기 조정, 메뉴 및 효과 |
| `dist/style.css` | 공통 스타일, 꽃 및 팝업 디자인 |
| `server.cjs` | 로컬 개발용 서버 |

`dist`는 빌드 산출물이 아니라 직접 편집하는 소스 폴더입니다. 세로 화면 스타일은 공통 스타일 위에 적용됩니다.

## 게임 규칙

- 화분 3개에 씨앗을 심고 물을 줍니다.
- 물을 준 뒤 5초 후 가지치기할 수 있으며, 기본 성장 시간은 45초입니다.
- 꽃봉우리를 눌러 색을 공개합니다.
- 서로 다른 화분의 꽃 2개를 10 골드로 교배합니다. 부모 꽃은 유지됩니다.
- 흰색 × 파랑 → 하늘색, 흰색 × 노랑 → 연노랑, 하늘색 × 연노랑 → 연하늘색.
- 지정 조합은 새 색 40%, 각 부모색 30%입니다. 희귀 변이는 별도로 먼저 판정합니다.
- 꽃을 판매하거나 같은 색의 보존 씨앗으로 전환할 수 있습니다.
- 성장 단축, 자동 물 주기, 희귀 확률 증가 아이템이 있습니다.

## 저장과 현재 범위

진행 상황은 브라우저 `localStorage`의 `petite-bloom-v1`에 저장됩니다. 같은 주소와 브라우저에서 유지되며 계정 동기화는 없습니다. 브라우저 데이터를 지우면 초기화됩니다. Google Fonts를 불러오며 연결이 없으면 기본 글꼴을 사용합니다.

실제 결제, 계정, 서버 데이터베이스, 모바일 앱 패키징은 포함하지 않습니다.
